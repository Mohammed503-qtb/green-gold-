# ذهب أخضر 🌿 | GREEN GOLD

**قات اليوم في عدن — بشوف ما بتستلمه قبل ما تدفع**

نظام تجاري متكامل لبيع القات بالدفعات الحقيقية: كل دفعة تُصوَّر يوميًا بكمياتها وأسعارها وصورها الحقيقية، تُحجز عند الطلب، تُدفع بإثبات يُتحقق منه يدويًا، وتُسلَّم برمز OTP — من الطلب حتى التقييم.

---

## 📦 محتويات المستودع (Monorepo)

| المسار | الوصف |
|---|---|
| `/` | **الباكند + الويب** — Next.js 16 (App Router) + TypeScript + Prisma/SQLite. يخدم واجهة الويب (متجر + إدارة) وكل واجهات REST API التي يستهلكها تطبيق الموبايل |
| `mobile/` | **تطبيق الموبايل** — Flutter (Android + iOS) عربي RTL بالكامل، Riverpod، يتصل بالباكند عبر REST |
| `.github/workflows/` | **خطوط CI/CD** — فحص جودة مستمر + بناء إصدارات موقّعة جاهزة للنشر (APK/AAB/IPA) مع GitHub Releases |
| `Dockerfile` + `docker-compose.yml` | نشر الباكند في بيئة إنتاج تجارية |

## ✨ الميزات الأساسية

- **الدفعات بدل المنتجات الثابتة**: كل دفعة لها كود فريد (`HZ-20260830-02`)، صور وفيديو حقيقي، وقت تصوير، تصنيف (💎 فاخر / ⭐ ممتاز / 💰 اقتصادي)، مقاييس جودة (نضارة/كثافة/امتلاء/مظهر)، وكمية محدودة — إذا انتهت انتهى العرض تلقائيًا.
- **سلة وشراء محميان من التلاعب**: الخادم يعيد حساب كل الأسعار دائمًا، ويمنع البيع فوق المتاح (409 برسالة عربية).
- **حجز مخزون بمهلة**: 30 دقيقة عند الطلب مع تحرير تلقائي للطلبات المنتهية.
- **دفع بإثبات**: تحويل بنكي / محفظة / دفع عند الاستلام. العميل يرفع الإثبات فقط — التحقق اليدوي من الإدارة (الموظف لا يستطيع أبدًا اعتبار دفعه «مدفوعًا»).
- **آلة حالات صارمة للطلب**: `بانتظار الدفع → إثبات → تأكيد → تجهيز → جاهز → خرج للتوصيل → تم التسليم` (+ ملغي/مرفوض/مسترجع/تعذر التوصيل).
- **تسليم برمز OTP**: لا تُغلق عملية التوصيل دون رمز من أربعة أرقام يُسلَّم للعميل.
- **تقييم مرتبط بالدفعات**: وجوه (😍🙂😐☹️) + «هل كان مطابقًا للصور؟» + تعليق — يظهر على بطاقة الدفعة في الكتالوج.
- **واتساب برقم الطلب**: زر مباشر برسالة جاهزة يحتوي كود الطلب (`ZG-XXXXXX`).
- **إدارة كاملة**: لوحة معلومات حية، إدارة الطلبات والدفعات، إنشاء دفعات بصور ومنزلقات جودة، مخزون وحركات، توصيل بـ OTP، عملاء، تقارير (مبيعات 14 يومًا / أفضل الدفعات / توزيع التصنيفات)، سجل تدقيق كامل (Audit Log) قبل/بعد.
- **صلاحيات الأدوار**: المالك / المدير / الموظف / السائق — كل دور يرى ما يخصه فقط.
- **إعادة الطلب** بضغطة، **إشعارات إدارية** (طلب جديد، إثبات دفع، مخزون منخفض، انتهت دفعة).

## 🚀 التشغيل السريع

### 1) الباكند + الويب (يجب أن يعمل أولًا)

```bash
bun install                 # تثبيت الحزم
bun run db:push             # إنشاء قاعدة البيانات
bun prisma/seed.ts          # بيانات تجريبية واقعية (دفعات + طلبات + موظفون)
bun run dev                 # http://localhost:3000
```

> التطبيق يعمل حاليًا بـ SQLite عبر Prisma. للإنتاج التجاري استخدم `docker compose up -d` (انظر أدناه).

### 2) تطبيق الموبايل

```bash
cd mobile
flutter pub get
flutter run                       # جهاز متصل / محاكي
```

عند أول تشغيل يطلب التطبيق **عنوان خادم المتجر** (مثل `https://api.example.com`) ويختبره قبل الحفظ. يمكن تغييره لاحقًا من «حسابي ← إعدادات الخادم»، أو تضمينه وقت البناء:

```bash
flutter build apk --release --dart-define=API_BASE_URL=https://api.example.com
```

### 3) النشر التجاري للباكند (Docker)

```bash
docker compose up -d --build     # يبني ويشغل الباكند + قاعدة البيانات
```

## 📱 الإصدارات (Releases)

كل وسم `v*` يشغّل خط بناء الإصدار الذي ينتج:

- `GreenGold-vX.Y.Z-android.apk` — حزمة Android موقّعة للتثبيت المباشر
- `GreenGold-vX.Y.Z-android.aab` — حزمة Play Store الرسمية
- `GreenGold-vX.Y.Z-ios-unsigned.ipa` — حزمة iOS للتوقيع بحسابك ثم النشر (TestFlight/App Store)
- `checksums.txt` — بصمات SHA-256 للتحقق من سلامة الملفات

اذهب إلى **Releases** لتنزيل أحدث إصدار جاهز للتثبيت.
